# Génération d'images et vidéos avec fal.ai

- Connecteur fal.ai branché à Claude : pas besoin de clé API, juste des crédits sur le compte.
- Kling 3.0 Pro (image → vidéo) : environ 0,14 $ / seconde, son généré inclus. Durée 3 à 15 s.
- Premier test (2026-10-10) : le chat qui applaudit, 3 s, environ 0,42 $.
- Prérequis cloud : le domaine `v3b.fal.media` doit être autorisé dans l'accès réseau de l'environnement.

Utilisé pour : [[Restaurants]].
